## OpenModelica Open Source Tools

{{< figure src="/images/omstructure.png" alt="omstructure" caption="Arrows denote data and control flow" >}}

### [Advanced Interactive OpenModelica Compiler (OMC)](/free-and-open-source-software/open-modelica-compiler-omc)

{{< tool image="/images/ModelicaTools/OMShell.jpg" alt="omc structure" image-title="omc structure" link="/images/omstructure.png" >}}

* Compiles Modelica code to C for Simulation.
* Provides an API to query the loaded Modelica code.
* Can be used from command line or interactively as a Corba object.

{{< /tool >}}

### [Interactive OpenModelica Shell (OMShell)](/free-and-open-source-software/open-modelica-shell-omshell)

{{< tool image="/images/ModelicaTools/OMS.jpg" alt="omshell" link="https://www.ida.liu.se/labs/pelab/modelica/OpenModelica/Screenshots/OMShell-screenshot.jpg" >}}

The purpose of OMShell is to provide an interactive environment for working with OMC.

{{< /tool >}}

### [OpenModelica Notebook (OMNotebook)](/free-and-open-source-software/omnotebook)

{{< tool image="/images/ModelicaTools/OMNotebook.jpg" alt="omnotebook" link="https://www.ida.liu.se/labs/pelab/modelica/OpenModelica/Screenshots/OMNotebook-screenshot.jpg" >}}

* A literate programming notebook.
* OMNotebook is a Mathematica style Notebook for Modelica.
* The purpose of OMNotebook is to provide an advanced Modelica teaching tool.

{{< /tool >}}

### <a title="Dr Control" href="/free-and-open-source-software/drcontrol" target="_blank">DrControl Under OMNotebook</a>

{{< tool image="/images/ModelicaTools/DrControl.jpg" alt="Dr Control" link="/images/ModelicaTools/Dr%20Control%20Usage.jpg" title="Dr Control Usage Senario" >}}

* DrControl is an interactive course material in control theory based on the electronic book OMNotebook.
* DrControl can be an alternative or complement to the traditional teaching method with lecturing and reading textbooks in control theory.

{{< /tool >}}

### [OpenModelica Connection Editor (OMEdit)](/free-and-open-source-software/omconnectioneditoromedit)

{{< tool image="/images/ModelicaTools/OMEdit.jpg" alt="OMEdit" link="/images/ModelicaTools/omeditexample.png" title="OMEdit Example" >}}

* Graphical Connection Editor
* Modelica annotation 3.1 is supported making the exchange of models to other tools easier
* Qt C++ libraries used
* Click the thumbnail for a screenshot

{{< /tool >}}

### [OMEdit Integrated with Electronic Notebooks and Interactive Simulation](/free-and-open-source-software/omeditintegration "OMEdit with Interactive Simulation")

{{< tool image="/images/ModelicaTools/OMEditIcon.jpg" alt="OMEdit with Interactive Simulation" link="/images/ModelicaTools/OMEditInteractiveSimulation.jpg" title="OMEdit with Interactive Simulation" target="_blank" >}}

* Gives students the facility to export/import models between OMEdit and electronic notebooks.
* Uses OpenModelica Interactive (OMI) subsystem to perform interactive simulation.
* Online simulation makes the simulation respond in real-time to user input.
* Click the thumbnail for a screenshot.

{{< /tool >}}

### OpenModelica Equation Model Debugger

{{< tool image="/images/omdebugger.png" alt="" >}}

* First ever model equations debugger for Modelica models
* Mapping run-time errors to source model position
* Showing equation trasformations of a model

{{< /tool >}}

### [OMOptim](/research/omoptim "OMOptim")

{{< tool image="/images/ModelicaTools/OMOptim.jpg" alt="OMOptium" link="/images/ModelicaTools/OMOptiumInterface.jpg" title="OMOptim GUI" target="_blank" >}}

* OMOptim facilitates optimization in engineering.
* OMOptim extends the capabilities of OpenModelica towards design optimization.
* It can be used to the increase energy efficiency of an industrial process.
* Click the thumbnail for a screenshot.

{{< /tool >}}

### [Modelica Development Tooling (MDT)](/free-and-open-source-software/modelica-development-tooling-mdt)

{{< tool image="/images/MDT/MDT.jpg" alt="MDT Screenshot" link="/images/MDT/MDT.jpg" target="_blank" >}}

* MDT provides an advanced development environment for Modelica within the Eclipse platform.
* Advanced textual environment for eclipse.

{{< /tool >}}

### [Modelica Modeling Language (ModelicaML)](/free-and-open-source-software/modelicaml)

{{< tool image="/images/modelicaml_concept.jpg" alt="modelicaml" link="/images/modelicaml_concept.jpg" target="_blank" >}}

* Graphical modeling language for the description of time-continuous and time-discrete/event-based system dynamics .
* Click the thumbnail for a screenshot.

{{< /tool >}}

### [OpenModelica Python Interface (OMPython)](/free-and-open-source-software/ompython)

{{< tool image="/images/ompython.jpg" alt="modelicaml" link="/images/ompython.jpg" target="_blank" >}}

* OMPython is a subsystem of the OpenModelica platform, enabling users to experience the modeling and simulation capabilities of OpenModelica within the Python environment.
* Click the thumbnail for a screenshot.

{{< /tool >}}

### [OpenModelica Simulator (OMSimulator)](/free-and-open-source-software/omsimulator)

{{< tool image="/images/OMSimulator/OMSimulator1.0.png" alt="OMSimulator 1.0 - TLM based simulator" >}}

* A new (stand-alone) FMI- and TLM-based simulation tool OMSimulator.
* First version for connected FMUs, TLM objects, Simulink models (via wrappers), Adams models (via wrappers), BEAST models (via wrappers), Modelica models.
  Regarding the FMI standard for model exchange and co-simulation , see [FMI standard](https://www.fmi-standard.org/).

{{< /tool >}}
