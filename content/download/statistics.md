title: "Download Statistics"
---

Number of downloads per month from [build.openmodelica.org](https://build.openmodelica.org/), updated once a day.

{{< download-statistics >}}

- **Windows** counts the downloads of the Windows installers (`.exe`), releases and nightly builds.
- **Linux** counts the downloads of the `omc` Debian package (`.deb`), which every installation or upgrade of OpenModelica from our [apt repository](/download/download-linux) fetches once.
- **Playground** counts how many times the [OpenModelica playground](https://playground.openmodelica.org/) loaded the compiler in a web browser.

Downloads from mirrors, the [Docker images](/download/docker) and the packages provided by Linux distributions are not included.

> [!WARNING]
> **Note:** the numbers are raw request counts from the web server log.
> They include everything: scrapers, bots, automated builds (CI) and humans, so the number of actual installations is considerably lower.
