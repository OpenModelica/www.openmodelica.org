## MetaModelica Course

This course is intended to teach the basics of MetaModelica language and to explain how the OpenModelica compiler is built.
Ask questions in [GitHub Discussions](https://github.com/OpenModelica/OpenModelica/discussions).

The links from below are useful for the course in MetaModelica:

- [The course material](https://github.com/OpenModelica/OpenModelica/tree/master/testsuite/metamodelica/MetaModelicaDev).
- [OMDEV](https://gitlab.liu.se/OpenModelica/OMDev.git) - everything needed to compile OpenModelica (and this course material).
- [MDT](https://github.com/OpenModelica/MDT) - the Eclipse plugin used as development environment (a full copy including Eclipse is provided, if you don\'t have it installed).
- [Documentation](/developersresources/devdocumentation), so you can read about the MetaModelica language.
- [Meta-Programming and Language Modeling with MetaModelica 1.0](https://urn.kb.se/resolve?urn=urn:nbn:se:liu:diva-66440) by Peter Fritzson and Adrian Pop, 2011
- [Towards Modelica 4 Meta-Programming and Language Modeling with MetaModelica 2.0](https://urn.kb.se/resolve?urn=urn:nbn:se:liu:diva-68361) by Peter Fritzson, Adrian Pop, and Martin Sjölund, 2011
- A [notebook](https://github.com/OpenModelica/OpenModelica/raw/master/testsuite/metamodelica/MetaModelicaDev/documentation/Basic-Exercise-MetaModelica.onb "Download file") with MetaModelica examples.
- [Writing efficient MetaModelica](https://trac.openmodelica.org/OpenModelica/wiki/WritingEfficientMetaModelica).
